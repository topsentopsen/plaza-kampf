Tutorial

Zwei Handys, ein Duell. Host teilt den Link — Gast tritt bei.

  • Bewegen ← → · Springen ▲ · Duck ▼
  • Block = Richtung weg vom Gegner (stehen oder ducken)
  • A leicht · B schwer · C Special
  • Light trifft → oft C canceln (Kombo)
  • Specials chippen durch Block · Lows brauchen Duck-Block
  • Querformat · ⛶ Fullscreen · iPhone: Home-Bildschirm
  • PWA: „Zum Home-Bildschirm“ = App ohne Safari-Leiste
  • Allein üben = lokaler Test gegen CPU/Dummy, kein Netz nötig
